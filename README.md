# OnlyYou (只有你) —— AstrBot 跨平台 AI 网友与深度拟人陪伴插件

> **“在各个群聊里，我是能和大家接梗互损、会顺手往群里丢沙雕视频的鲜活 AI 网友；我每天通过 Roguelite 随机引擎在【休息中 / 繁忙中 / 空闲中】三种状态间切换，在繁忙时只抽空理熟人和你，在空闲时主动刷视频、聊今天的奇遇——并会根据你的消息或刷到的视频临时微调我的安排。”**

---

## 1. 核心设计总览

**`astrbot_plugin_only_you`（OnlyYou）** 旨在解决传统 AstrBot 机器人“被动客服感”、“日程死板千篇一律”以及“群聊乱接话”三大痛点，围绕以下核心模型构建：

### ① 🚦 极简而强大的“三态 × 双行为”控制模型
剥离冗余分类，AI 网友在底层实际可执行的**具体行为只有两类：【回/发消息】与【刷视频】**；而每日随机生成的每一件日程事项，都唯一绑定到以下**三种状态**之一：

| 当前状态 | 典型日程事项示例 | 对行为一：【回/发消息】的控制 | 对行为二：【刷视频 (B站/抖音)】的控制 |
| :--- | :--- | :--- | :--- |
| **💤 休息中 (`RESTING`)** | 深夜睡觉、午休补觉 | **完全不回任何消息**（仅静默记录群聊窗口），不主动发消息 | **停止刷视频** |
| **🔥 繁忙中 (`BUSY`)** | 上早八课、开会、赶稿、打排位 | **只回复 L2重要用户 & ★L3核心用户**（抽空简短回一句），**完全忽略 L1普通用户**，不主动水群 | **停止刷视频** |
| **☕ 空闲中 (`IDLE`)** | 吃饭下饭、躺平摸鱼、晚间玩手机 | **全量开放**：群聊 L1/L2/L3 读空气接话 + 可拿今日**【奇遇卡】**或刚刷的视频主动找人搭话 | **主动开启刷 B站/抖音**，看热评+多模态看画面并分享 |

### ② 🎲 Roguelite 随机日程引擎 + 【奇遇谈资卡】
- **拒绝千篇一律**：每天像开一局 Roguelite 游戏一样，从固定元素池（通用池 + 基于 AstrBot 原生 Persona 派生的专属池）中随机抽取 **【今日基调卡】×【时间槽事件状态卡】** 排满一天，决定今天什么时候处于 `休息中 / 繁忙中 / 空闲中`。
- **🃏 奇遇谈资卡（短时记忆话题）**：每天随机抽取 `1~2` 张 **【奇遇卡】**（如 *“今天点外卖老板多送了一根烤肠”*、*“早上下楼差点被流浪猫绊倒”*），不改变底层三态逻辑，纯粹作为当天的短时记忆谈资——让它在 `空闲中` 找你或群友聊天时言之有物，聊过一次即消耗。

### ③ 🔄 输入驱动的受限日程微调（根据用户消息或刷到的视频）
- **无输入不变卦**：AI 绝不凭空乱改计划，只有收到高冲击力的真实外部输入——即 **读取到的用户消息**（如 ★L3核心用户找它、或 L2熟人群聊爆大瓜）或 **刚刷到的 B站/抖音高分视频** 时，才会击穿当前卡片定力并微调状态：
  - 例 1：收到核心用户/熟人高热消息 $\rightarrow$ 将当前时段从 **`繁忙中 (BUSY)` 微调为 `空闲中 (IDLE)`**（放下正事摸鱼陪聊）。
  - 例 2：在 `空闲中` 末尾刷到超搞笑视频或正在热聊 $\rightarrow$ **推迟下一时段 `休息中/繁忙中` 的开始时间**（熬夜加钟继续冲浪/陪聊）。
- **三重防失控限制**：受 **每日最大微调次数（默认 2 次）**、**微调冷却锁（120 分钟）** 与 **卡片定力护甲** 严格限制，绝不无限摇摆。

### ④ 💖 三级用户关系体系（L1 普通 / L2 重要用户 / ★L3 核心用户）
- **L1 普通用户**：仅在 Bot 处于 `空闲中` 时通过群聊读空气互动；`繁忙中` 直接忽略。
- **L2 重要用户（群聊熟人，支持好感度自动晋升）**：即便 Bot 处于 `繁忙中` 也会抽空回复；在 `空闲中` 刷到对口视频会在群里主动 `@` 他。
- **★ L3 核心用户（管理员 / OnlyYou）**：最高优先级，你的消息最容易击穿它的 `繁忙` 护甲让它停下手头事陪你；独享高频私聊陪伴与“群聊吃瓜，私聊耳语”。

### ⑤ 🧠 精简版分级记忆、定时自动遗忘与上下文预算管理
- **参考并精简自 `livingmemory`**：剔除笨重的 2D/3D 图谱看板与高延迟的 Agent Tool 函数调用，采用轻量化单表 SQLite + 混合打分召回。
- **三级记忆与定时遗忘（Forgetting GC）**：将记忆划分为 **Tier 3 核心记忆（永久保留重要事实与约定）**、**Tier 2 近期记忆（按重要度与访问次数动态衰减）**、**Tier 1 瞬时记忆（今日奇遇与刚看的视频，活 48h）**。每日凌晨定时程序自动结算活力值并**物理清理**不重要的过期记忆。
- **简易上下文预算管理器（Context Budget Manager）**：自动截断过长的 AstrBot 原生历史消息，并严格限制单次注入记忆的最大条数（默认 `<= 6条`）与总字数预算（默认 `<= 400字`），彻底杜绝上下文窗口超载与 Token 费用失控。

### ⑥ 🔌 多模型统一调度网关 (`ModelHub`) 与 AstrBot 平台配置协同
- **6 类模型统一接口 + 留空自动继承**：内置 `ModelHub` 网关，统一管理 **对话主模型、小脑轻量文本模型、多模态视觉模型、Embedding 向量模型、Rerank 重排模型** 及预留的 **TTS 语音与 T2I 生图模型**。所有槽位复用 AstrBot 平台的 Provider 选择器（`_special: select_provider`），留空时自动继承当前会话（`umo`）所属平台配置文件的模型，缺失 Embedding/Rerank 时自动无感降级为关键词检索。
- **不重造轮子、不与平台配置打架**：
  - **黑白名单**：插件不设冗余黑白名单，100% 遵循平台访问控制与多配置文件开关。
  - **唤醒与分段/流式/TTS 管线复用**：被动消息通过 `event.should_call_llm(True/False)` 协同原生管线，直接复用平台配置的 `segmented_reply`（分段回复）、`streaming_response`（流式输出）与原生 TTS；后台主动推送则直接读取 `self.context.get_config(umo)` 的分段参数，保持全局体验统一。
